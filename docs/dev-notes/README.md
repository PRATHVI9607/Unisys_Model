# Development notes

They are kept for traceability and are not part of the KubeHeal product; the project documentation is in `docs/` and `docs/kubeheal/`.
`F3-attempts/` holds captured output from the first two F3 containment windows; the accepted run is in `docs/kubeheal/demo-evidence/F3/`.
